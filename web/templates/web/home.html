Football Field Reservation API

Backend capstone project. This server provides authentication, field management, availability checking, reservations with conflict prevention, and notifications.

Try the API

  • API Root
  • Swagger UI
  • Fields endpoint
  • Reservations endpoint

What’s implemented

  • JWT auth (register/login/refresh)
  • CRUD fields + availability
  • Reservations + cancel + conflict prevention
  • Notifications (stored + mark-all-read)

Quick start

  1. Install deps: pip install -r requirements.txt
  2. Run migrations: python manage.py migrate
  3. Create admin: python manage.py createsuperuser
  4. Start server: python manage.py runserver

Demo flow

  1. Register: POST /api/auth/register/
  2. Login: POST /api/auth/login/
  3. Create field (admin) or via POST /api/fields/
  4. Check availability: /api/fields/<id>/availability/?date=YYYY-MM-DD
  5. Create reservation: POST /api/reservations/
  6. See notifications: GET /api/notifications/
